# Attendo 🎓

Attendo is a beautiful, gesture-driven Progressive Web App (PWA) designed for students to track their class attendance, monitor their progress, and ensure they meet their target attendance goals with a flawless UI.

## Features ✨

* **Tinder-like Swiping Interface:** Mark your attendance with satisfying physics-based swipe gestures (Swipe right for present, swipe left for absent, tap for cancelled).
* **Smart Dashboard:** View your classes for the day with instantly updating visual rings indicating your attendance target health.
* **Intelligent Statistics:** Detailed metrics showing your total classes, attended ratio, missing margin, and subject-specific breakdowns.
* **Progressive Web App (PWA):** Installs directly to your home screen with a beautiful custom app icon. Works fully offline!
* **Offline-First:** All data is kept strictly on your local device. 
* **Data Portability:** Easily export and import your attendance data via JSON files.

## Getting Started 🚀

Attendo is a static client-side web application. There's no backend setup required.

1. Clone this repository.
2. Serve the directory using any static file server (e.g., VS Code Live Server or `npx serve`).
3. Open `index.html` in your browser.
4. On mobile, tap "Install App" or "Add to Home Screen" for the full PWA experience.

## Technologies Used 🛠️

* HTML5 & Vanilla JavaScript (ES6+)
* CSS3 with custom CSS Variables & Flexbox/Grid
* Native browser LocalStorage API
* Service Workers for offline caching and PWA installation
