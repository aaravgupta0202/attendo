# Attendo

Attendo is a swipe-based attendance tracker designed to help you mark classes, check statistics, and never miss your target.

## Features

* **Swipe-based Interface:** Easily mark your attendance with intuitive swipe gestures.
* **Statistics & Tracking:** Keep track of your attendance percentage and history.
* **Progressive Web App (PWA):** Install it on your device for an app-like experience. Offline capabilities included.

## Getting Started

1. Clone this repository.
2. Serve the directory using any static file server (e.g., `python -m http.server`, or VS Code Live Server).
3. Open `index.html` in your browser.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Service Workers (for PWA functionality)
